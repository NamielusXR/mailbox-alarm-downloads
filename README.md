# Mailbox Alarm downloads

Signed Android releases of Mailbox Alarm, a GPS reminder that sounds a loud alarm within 50 meters of a mailbox pin.

[Android releases](https://github.com/NamielusXR/mailbox-alarm-downloads/releases/latest)

APK filenames include their version. This repository contains the public APKs, checksums, and the version manifest read by **Settings > App updates**. Public APKs contain no preset personal mailbox location. Choose your pin by holding on the map or entering coordinates on a new installation. Updates preserve a pin already saved on the phone.

If you use the preconfigured 1.0.0 or 1.0.1 edition, first install and open the preset 1.0.2 APK from the [private project](https://github.com/NamielusXR/mailbox-alarm/releases/tag/v1.0.2). This saves the original default pin before switching to public update APKs. Do not uninstall for an update; that removes saved settings.

## Install and update

1. Download the versioned APK from Releases and open it on Android 8 or newer.
2. Allow installation from your browser or Files app when Android asks, then install.
3. Choose your mailbox pin, test the alarm, and start reminders with precise location and notifications enabled.
4. In Settings, view live GPS accuracy and set up lock-screen alarms and battery access.
5. For later releases, use **Settings > App updates > Check for updates**, then **Download** and **Install**. Android still asks you to confirm installation.

The app verifies update checksums, versions, and signing certificates before installation. APKs use the same signing certificate as the original release. GPS reminders work offline; maps and app update downloads need internet. No GPS readings or mailbox coordinates are sent with update requests. There is no app account or analytics.
